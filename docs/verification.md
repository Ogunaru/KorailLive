## 2026-11-25 README 개편

이 저장소에서 실행하는 검사는 공개 범위 검사와 로컬 링크 검사 두 가지다. 예전 공개 샘플(`samples/`)과 그 빌드·테스트 작업은 이번 개편에서 지웠으므로, 과거 샘플 테스트 결과는 현재 검증 근거로 쓰지 않는다.

| 확인 | 방법 | 결과 |
| --- | --- | --- |
| 공개 범위 | `node tools/check-public-boundary.mjs` | 통과 |
| 로컬 링크·이미지 | `node tools/check-local-links.mjs` | 통과 |
| 코드 발췌 | README의 코드 블록을 iOS `00a3d2b`, 서버 `d96b5ba`의 원본 파일과 비교. 원문 블록은 줄 단위 일치, 축약 블록은 모든 코드 줄이 원본에 같은 순서로 있는지 확인 | 5개 블록(6개 구간) 일치 |
| Mermaid | 두 그림을 Mermaid 11.12로 파싱·렌더링 | 오류 없음 |
| 화면 판독성 | GitHub GFM 렌더러가 만든 HTML을 데스크톱(880px)과 모바일(390px) 폭으로 캡처 | 데스크톱은 모두 읽힘. 모바일은 화면 캡처의 주요 값은 읽히지만 작은 라벨과 상태 그림(SVG)의 글자는 확대해야 읽힘 |

화면 이미지의 출처는 다음과 같다.

- 전광판·탑승 정보: iOS `00a3d2b`를 임시 복사본에서 빌드해 iPhone Duo 시뮬레이터(iOS 27.2)에서 실행했다. 복사본에서는 번들 ID를 바꾸고 서버 응답을 합성 JSON으로 대체했으며, 실행 인자로 광명역 전광판과 탑승 정보 화면을 열었다.
- Live Activity 카드 두 장: 같은 복사본의 앱 화면에 위젯 확장의 잠금화면 뷰 코드를 렌더링한 프리뷰다. 시스템 잠금화면, ActivityKit 시작, APNs 수신은 거치지 않았다.

README가 인용하는 서버 Actions 결과(2026년 11월 25일 main 실행의 `swift`·`scenarios` 작업과 배포·승격)는 비공개 서버 저장소의 실행 로그에서 확인했다. 실기기 Live Activity 수신은 이번 확인 범위가 아니다.
